# Dixa Messenger iOS SDK

Add the Dixa Messenger to your iOS app, so your users can chat with your support team.

## Get started

In Xcode, select **File > Add Package Dependencies…** and enter this URL:
```
https://github.com/dixahq/ios-messenger
```

Then follow the [iOS SDK guide on docs.dixa.io](https://docs.dixa.io/docs/dixamessenger/ios/overview).
